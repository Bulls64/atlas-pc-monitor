ATLAS PC 2.0
============

Application de bureau en Python pour consulter l'inventaire matériel d'un PC
Windows, dans l'esprit des utilitaires comme Speccy.

Lancement
---------
Sous Windows 10 ou 11 avec Python 3.9 ou plus récent : double-cliquez sur
lancer_atlas.bat, ou lancez  python atlas_pc.py

Aucune bibliothèque externe n'est requise : l'application utilise Tkinter et
une seule requête PowerShell/CIM.

Ce que l'application affiche
----------------------------
- Vue d'ensemble : modèle du poste, processeur, mémoire, carte graphique,
  carte mère, stockage, températures
- Système : fabricant et modèle, Windows (édition, version, activation,
  durée depuis le démarrage), démarrage sécurisé, TPM
- Processeur : socket, cœurs, fréquences, caches, virtualisation
- Mémoire : installée et utilisable, emplacements, et par barrette le type
  (DDR4, DDR5...), le format, la vitesse nominale et configurée
- Carte mère : carte, BIOS/UEFI, zones thermiques ACPI
- Graphiques : cartes (mémoire lue dans le registre, donc juste au-delà de
  4 Go), pilote, écrans (diagonale, année, numéro de série)
- Stockage : type réel SSD/HDD, interface NVMe/SATA, santé, heures de
  fonctionnement, usure, volumes, BitLocker
- Réseau : cartes, MAC, IPv4, IPv6, passerelle, DNS
- Audio et Batterie (usure calculée sur les portables)

Certaines sources (TPM, BitLocker, démarrage sécurisé, compteurs de fiabilité
des disques, températures) exigent une session administrateur : le bouton
« Relancer en administrateur » apparaît quand c'est utile, et chaque page
indique pourquoi une information manque.

Actions
-------
- Recherche (Ctrl+F) dans toutes les pages, sans tenir compte des accents ;
  Échap pour revenir
- Copie : Ctrl+C sur les lignes sélectionnées, double-clic pour copier une
  valeur, clic droit pour le menu ; « Copier le rapport » pour tout copier
- Export en JSON, texte ou HTML (l'extension suit le type choisi)
- Comparaison avec un ancien rapport JSON : liste ce qui a changé sur le poste
- Thème clair ou sombre, mémorisé dans %APPDATA%\AtlasPC\config.json

Ligne de commande
-----------------
  python atlas_pc.py --json            inventaire JSON sur la sortie standard
  python atlas_pc.py --text            rapport texte
  python atlas_pc.py -o rapport.html   rapport dans un fichier (.json .txt .html)
  python atlas_pc.py --debug           journal détaillé (dossier temporaire)
  python atlas_pc.py --help

Organisation du code
--------------------
  atlas_pc.py          lanceur
  atlas/collect.py     script PowerShell, appel, normalisation
  atlas/formatting.py  mise en forme des valeurs (fonctions pures)
  atlas/pages.py       contenu des pages, recherche, comparaison
  atlas/export.py      JSON, texte, HTML
  atlas/ui.py          interface Tkinter
  tests/               tests (pytest)

Développement
-------------
  pip install -r requirements-dev.txt
  pytest                       tests
  ruff check . ; ruff format . contrôle et mise en forme
  pyinstaller atlas_pc.spec    exécutable autonome dans dist/
